# pi-goui

独立的 Go / Bubble Tea v2 终端前端。保留现有 **pi 核心、工具、配置及 RPC 支持的扩展**，不套用 pitago 的整套界面。

```bash
./pi-goui/run.sh                         # 在调用者当前目录启动
./pi-goui/run.sh --cwd /path/to/project
./pi-goui/run.sh -c                      # 恢复当前目录最近的会话
./pi-goui/run.sh --session /path/to/session.jsonl
./pi-goui/run.sh --check                 # 只检查 RPC，不发提示词、不保存会话
```

需要 Go 1.26+ 和已安装的 `pi` / Node.js。启动脚本构建本地 `bin/pi-goui`；`PI_BIN` 或 `--pi` 可指定 pi 可执行文件。`--no-session` 不保存会话；`--` 后可传模型、工具及扩展等启动选项，例如 `-- --model provider/model --no-extensions`。不允许覆盖 RPC 模式、会话归属或传入位置提示词。

## 界面与会话

- 本次运行中完成的助手回复会在气泡标题追加 working 统计：`模型名 · ↑35k ↓1k · 28s`。数值在完成时冻结，输入量为主会话最新一轮的上下文输入大小（`input + cacheRead + cacheWrite`，不逐轮累加），加上 Worker 卡片显示的累计 `input`（不含缓存）；输出量汇总主会话与 Worker 的累计模型输出；Worker 每轮 `↓` 与主会话采用相同口径：流式期间估算正文、thinking 和工具调用，完成时以模型上报的 `output` 为准（缺少 usage 时使用估算），不计工具返回内容；仅保存在当前前端会话中，重启后不推算历史耗时。窄窗口按标题宽度截断。
- 默认正文配色来自 `themes/pi.json`，可用 `/theme` 切换预设；用户、助手、工具、Worker、codemode、输入框、系统消息、侧栏和弹窗各用独立渐变，每套主题有自己的边框配色预设；优先读取 agent 配置目录中的同名主题，缺失时使用内嵌版本。界面、消息、代码块与输入框保持透明；仅选中的会话卡片使用 workbench 灰色底和加粗高亮。
- 消息列表滚动条不预留列，仅在滚动且内容超出可视高度时临时覆盖消息区最右侧，允许穿过正文或气泡边框，停止滚动约 0.8 秒后隐藏并恢复内容；使用与 RECENTS 滚动条一致的灰色，不影响输入框、消息布局或复制内容。滚动条仅作位置提示，不支持拖拽。
- 右侧采用完整细框与缩进横分隔线；左上角不重复会话标题，窄终端自动隐藏侧栏。
  - **SESSION**：名称、工作目录、可选 Git 状态、CTX 进度条和上下文用量。Git 状态约每 5 秒异步只读刷新。新建且没有消息或运行任务的会话可点击目录，在弹窗中设置 cwd（绝对路径、相对当前目录的路径或 `~/`）；自动列出匹配目录，↑↓ 选择、Tab 补全，也可点击目录逐级进入或点击 `../` 返回上级。Enter 确认输入框中的目录、Esc 取消。只重启该空会话的后端，保留未发送草稿和图片，不影响其他会话。
  - **STATS**：`in / out`、`cache / cost` 两行两列，字段和值只隔一个空格；数量用 `K/M`，费用显示美元两位小数。`cache` 为 `cacheRead / (input + cacheRead + cacheWrite)`。
  - 仅官方 Codex OAuth 身份显示剩余 Weekly limit、重置时间及整数 Credits；异步查询固定官方地址，不刷新或复制凭据，不使用代理或跨域重定向。
  - **RECENTS** 显示在区域顶部；**+ New session** 固定在历史列表下方，之间留一空行，整行内部区域可点击。历史每条仅占一行，显示会话名称；与 `/resume` 一样按父子会话分组，父会话在前、子会话以轻量缩进和 `↳` 紧随，同组按最近活动排序。最多显示 5 条（空间不足时减少），在历史列表上滚轮可查看当前目录更早的会话，右侧细滚动条提示位置；全量历史每 5 秒异步刷新。名称缩进且不显示编号，悬停时显示淡紫色文字，长名称省略；悬停详情浮窗显示在列表左侧，包含换行的完整名称和本地最后修改时间，不占布局空间；空间不足时裁切内容或隐藏浮窗，移开鼠标即消失；点击时优先切换到已打开的目标标签；当前标签为空且空闲时复用，否则在新标签中打开并保留原会话、草稿和运行任务。点击名称行可打开会话；区域下方留一空行连接双行已打开会话卡片，不加分隔线，两份列表独立滚动，无折叠及 SESSIONS 标题。仅选中卡片有灰底和加粗；正式名称优先，无名称时回退到首条已提交用户输入（仅显示，不写入名称）。
- Worker 的右侧只读会话详情不创建标签页或 RPC 写入进程，不提供任务输入或取消入口；主会话仍可正常操作。详情仅隐藏 fork 继承历史，保留本次任务的用户输入、中间助手消息、thinking、工具调用及结果和最终回复，复用主会话的渲染与折叠逻辑；流式正文与中间活动实时更新。用户输入中的真实 Worker 契约以紧凑 Markdown 展示，文件范围和验收条件等按字段整理，普通文本与非契约 JSON 保持原样；用户消息的顶层项目/编号列表超过 8 项时默认显示前 5 项，点击“展开剩余 N 项”或“收起列表”切换，嵌套内容随完整父项保留，代码块不折叠，原始记录不变。列表折叠状态在当前任务详情内独立保存，调宽和内容追加不重置；操作列表时暂停自动跟随以避免位置跳动。最终结论使用与主聊天相同的 Markdown 渲染，保留标题、列表、表格和完整代码块；最后一条助手回复若是完整 Worker JSON 报告，会按摘要、验证、验收、风险等分节美化为 Markdown，未知字段完整保留，原始记录不变（普通 JSON 与未完成的流式片段不转换）；默认自动滚到最新内容，手动向上滚后暂停跟随，滚回底部后恢复；拖选文字时也暂停跟随，避免复制位置跳动。独立滚动和拖选复制，边框、关闭按钮及拖动调宽保持不变。Esc 或 `关闭 ×` 关闭详情，不停止任务。新任务的真实消息记录位于 `~/.pi/worker-transcripts/<UUID>.jsonl`（自定义 agentDir 时为 `dirname(agentDir)/worker-transcripts`；旧 `agentDir/worker-transcripts` 仅在新位置缺失时兼容读取，不自动搬迁，也不纳入新目录容量清理）（目录 0700、文件 0600；含真实消息/工具内容，非加密存储），每任务最多 64MiB，达到限制或记录失败会明确显示不完整；新日志只保存本次任务，不再复制 fork 继承历史（执行时仍正常继承上下文，旧日志仍兼容）。日志总量在 10 GiB（10 × 1024³ 字节）内全部保留；超过后按最后修改时间优先删除最旧的已结束日志，保护仍在运行的任务。`.active` 是日志删除保护标记，不会阻塞新任务或详情读取；宿主异常退出后，后续检查可识别死亡进程并回收，损坏或无法确认的标记则保守保留占用，不属于死锁。仅在任务开始/结束时触发检查，日志目录用一个 `.retention.lock` 文件记录上次检查时间，24 小时内不再扫描（失败也保留时间戳，次日再尝试），不逐条消息检查；过期锁接管采用尽力而为的排他创建，不引入分布式协调机制，删除前仍校验文件身份和活跃状态。这是软上限，活跃或无法确认已结束的日志可暂时超额，无后续任务则不后台扫描。记录未保存、标识无效、文件不存在（可能已清理）或首次读取失败时，仍可打开任务的“简要详情 · 完整会话记录不可用”，展示当前任务快照中的目标、状态、摘要、验证及风险，不显示协议字段或其他任务。已读取部分真实消息后发生错误时保留这些消息并标记记录不完整；不会持续重试失败记录，重新点击查看可重试。简要详情随任务快照更新，但不能恢复已清理或从未保存的完整历史。
- `/new` 或侧栏 **+ New session** 创建独立 pi RPC 子进程。通过恢复选择器恢复历史时，仅空会话复用当前标签；非空会话（含草稿或运行任务）保留原标签，新建活跃标签并切换过去；目标已打开则切换过去，不启动第二个写入进程。普通切换不取消后台任务，各会话保留草稿、消息、滚动和扩展对话框。
- 选择弹窗水平居中、下沿紧贴输入框，保留聊天背景。会话选择器中 `Ctrl+R` 重命名选中项；`Ctrl+D` 打开删除确认，Enter 删除、Esc 取消。删除运行中的会话会先停止其进程；最后一个会话删除后创建空白标签。未打开历史的重命名只追加原生 `session_info`，不重写正文；直接文件操作拒绝损坏、旧版、符号链接或身份变化的历史。不要在其他 pi 进程中同时修改同一文件。
- 拖动右侧 sidebar 或详情栏的左边框可调整宽度（光标显示横向调宽提示）。两者分别记住本次运行的宽度，重启恢复默认，不写入配置；sidebar 最小 24 列、详情最小 20 列，并为主聊天保留至少 40 列。窄屏隐藏 sidebar 或全屏详情时不可拖动；窗口缩小临时限制宽度，放大后恢复偏好。拖动期间仅裁切/补齐当前显示内容以快速预览宽度，松开后按最终宽度完整换行和高亮；流式数据继续接收，不会丢失。
- 鼠标靠近已展开工具结果框的右上角时，框内显示 `查看 ↗`（两侧留白均可点击），移远后恢复原内容；点击打开右侧完整结果栏，临时替换会话侧栏。正文独立滚轮滚动、可拖选复制，长行换行，不受主视图的 10 行或 100 列预览限制，并同步流式更新；结果栏使用与侧栏一致的完整边框，右上角常驻 `关闭 ×`，点击文字或左侧留白，或按 Esc 关闭（对话框优先），恢复会话侧栏。小于 60 列时改为全屏结果视图，切换会话或工具消失时关闭。详情按工具类型分区展示：read/write 使用完整行号代码，edit 展示增删差异，命令与 codemode 分离代码、输出和调用记录，Worker task 在状态/模式/等级行（如 `✓ implement · deep`）末尾有独立 `查看 ↗` 入口，在右侧详情栏显示真实只读会话，复用主聊天完整渲染与折叠逻辑（含预览截断），完整工具结果通过栏内 `查看 ↗` 下钻；主会话位置不切换，不新建标签页。运行时增量更新；一批相邻同内容块的 token 增量合并投影，文档按内容/宽度/折叠状态缓存，鼠标移动和滚动不重建全文。详情独立滚动和复制，左边框可拖动调宽；拖动期间冻结全文重排，释放后更新，关闭详情恢复 sidebar。不提供 Worker 总览入口；旧任务没有真实会话记录时回退到明确标注的简要任务详情，不用 Activity 冒充完整会话；ask_question 显示问题与真实选项状态；web_search/fetch_content/source_check/get_search_content 分别展示查询、来源、引用和分页摘录，update_plan/web_enable/obs_recall 展示计划、能力启用和存储观察记录；未识别字段仍完整展示，不套用主视图截断，图片仍从主视图附件入口打开。详情渲染统一放在 [`internal/render/tooldetail/`](internal/render/tooldetail/README.md)，每种工具独立文件；新增工具通过该包静态入口接入。
- 消息标题为「你」、当前模型名称、「系统」；消息框之间不额外留空行，正文段落保留。Markdown / 代码高亮由前端渲染。**工具调用统一默认分组，单个也显示 `1 calls`**，组标题显示调用次数、类型分布、失败/运行数和估算 token；整个工具组与后续说明文本之间留一空行；说明文本后接工具组、组标题后接子工具均不留空行。展开的子调用和结果框整体缩进两格。
  - `read`：保存的文件片段、真实起始行号与语法高亮；`edit`：优先使用结果里的真实 diff，红绿标注增删；`write`：文件信息与待写入/已写入源码。
  - 执行期间，最新组左侧折叠箭头替换为`⋯`，颜色与执行中工具一致，结束后恢复 `›`/`⌄`；`n calls` 及后续工具计数、失败数、token 统计整行参与高光扫过，保留各段非运行时的原有底色，仅叠加助手配色高光（约 1.2 秒一轮，含短暂停顿），不再显示独立 Running 标题；仅刷新显示颜色、不改变位置或复制内容。调用列表紧接组标题，不加空行；执行中收起时仅预览最近 3 次调用，各条调用与正常列表共用折叠状态，可点击单独展开/收起结果，省略更早调用时首行显示 `…`，展开时显示全部调用且不叠加预览，只有最近三条中的 Worker 默认完整展开，更早的 Worker 默认收起；单个 Worker 的显式手动折叠状态优先。Worker 仅在最近 3 次调用范围内默认显示完整任务卡片，可点击 Worker 标题手动展开/收起，状态更新和完成不会覆盖手动选择；被更新调用挤出范围后立即省略，与其他工具遵循相同的最近三条规则。下一段助手说明文本出现、执行结束或出现新会话消息边界后移除；组默认仍收起，展开/折叠只改变调用列表范围，不影响运行状态动画。历史会话不自动展示该状态区。
  - ask_question 使用紧凑问答卡片：问题在上，选项在下，已选项以 `✓` 和成功色突出，未选项弱化；自定义答案单独标注，支持多选、多题、等待和取消状态，不再重复展示 Parameters/Result/Metadata。
  - read 卡片仅保留路径和必要参数，以及前 8 个终端行的带行号内容；搜索、列表和未知/MCP 工具将参数压缩为一行 dim 文本，结果最多预览 8 行，不再显示 Parameters/Result/Metadata 分节。长内容标注截断，卡片按内容收紧，完整记录保持不变。
  - edit/write 卡片参考 Zentui 的变更网格，不显示参数区或结果区。实际 diff 优先使用：内容宽度至少 72 列时显示 old/new 双栏，窄屏回退 unified；带源行号、红绿变更条和语法高亮，背景透明；内容区最多 100 个终端显示列，长行截断而不换行，双栏分别截断，窄窗口服从可用宽度。没有实际 diff 时，edit 明确标注替换预览；工具结果外框保持原样，仅调整框内样式。write 在参数生成和执行期间以 `writing 文件路径` 持续预览已收到的内容（包括尚未闭合的 JSON 字符串），成功后改为中性 `written 文件路径`，显示带行号和绿色变更条的写入内容：展开时仅显示最后 10 个源码行，前面的内容显示隐藏行数，不提供二次展开，保留原始行号与语法状态（不推断原文件为空）；结果携带真实 diff 时保留完整差异上下文，执行中仍标为 `writing`；预览反映内容生成进度，不代表文件已逐行落盘。失败时保留错误提示，不读取当前文件补造旧内容。
  - bash 卡片去掉命令行号及 Parameters/Result 标题，参数存在时以 dim 颜色括号追加到命令末尾（如 `(Timeout: 10)`）；无输出显示 `(no output)`，长输出最多预览前 8 个终端行并标注截断，完整输出保留在会话记录中。卡片按可见内容收紧宽度。
  - codemode 显示高亮源码和实际内部调用 trace；worker 始终归入 calls 组，不因运行状态自动展开；默认收起，外层组折叠时仅保留组标题，不显示任何子调用或卡片。卡片显示状态、目标、实际用量和耗时，不显示模型供应商/名称及 fork/new 模式；目标以 `◦` 展示，结论以 `•` 列表展示，进展显示缩进文本；目标和结论不使用竖线或重复的状态图标，标题、目标、结论之间不额外留空行。卡片按内容收紧宽度，多个 task 之间用 Worker 边框色横线分隔且上下不额外留白；耗时四舍五入为整数秒。目标与结论之间显示 steps 区，将工具调用与 thinking 按快照顺序合并，固定展示最近 3 条 step，不提供展开功能；thinking 使用 `!`，去掉 `**` 并拆开连续标题，不再在底部重复显示。标题固定为 `≡ Activity`，不显示总计数，明细及 `… n items (已折叠)` 再缩进一级；step 总数包含工具总数和快照中保留的 thinking 条目，不推算已丢弃的 thinking；不显示成功/失败汇总或工具级 token 用量。普通 calls 分组不显示成功数，仅有失败时显示 `n❌`（如 `3❌`）。尚无结论时按快照顺序显示说明文本。Worker 收起时仅显示一行批次概要，展开后才显示任务明细；单个 task 固定展开且点击不折叠，批次与 calls 组仍可折叠。其他命令、搜索、问答及未知工具使用代码、字段、列表和文本结果展示，不倾倒协议 JSON。实际读写的 JSON 文件仍按源码显示。没有真实 diff 时明确标注“请求的替换预览”，失败操作不会显示为已成功写入。
  - 状态/暗色摘要以及 token 分级参考 `extensions/ui/folding.ts` 和 `tool-tokens.ts`。`≈… tok` 是历史参数及结果的体积估算，**不是计费 usage**。
  - 可视化只使用保存的调用和结果，不重新读取当前磁盘文件。点击单个工具查看详情；`Ctrl+T` 显示或隐藏思考。
- 从 `get_entries` 读取**当前完整分支**，保留压缩前的消息；压缩显示**系统框内一行概要**，不铺开长摘要，也不修改或丢弃原始历史。sol-pi 在线压缩另显示 `≈80K → 24K tokens · −70%`：同口径的压缩前后内容估算值及 token 变化百分比（非计费 usage），指标随历史保存，窄屏自动换行。没有指标的旧记录仍只显示概要。其他树分支可在 `/tree` 浏览，不混入当前聊天。
- 鼠标拖选聊天或工具输出，松开后复制纯文本；拖选不会触发折叠。复制使用 **OSC 52**，需要终端允许写入剪贴板；不支持时可用终端自带的 Shift+拖选及复制功能。
- 向上滚动后，输入框上方出现 **123/345 [↓ Latest]**：按当前分支的消息记录计数，而非终端行数；前者是可见底部消息序号，后者是总数。点击 Latest 或按 `Ctrl+End` 回到最新并恢复跟随。
- 输入底栏左侧为有效快捷键，右侧点击模型打开选择、点击思考强度直接循环。使用真实终端光标供输入法定位；候选窗的最终行为仍取决于终端和输入法。working 行紧贴输入框，轮次显示为 `n turns`，运行时无左侧转轮，文本采用输入框边框同款的左右渐变配色，并叠加流动高光（约 1.2 秒一轮），随主题同步切换，完成后停止动画并保留静态 `✓`；空闲不显示 Ready；完成指标保留到下一次输入，复制提示以短暂 toast 显示。
- `/` 支持模糊搜索（`fast` → `codex-fast`、`cpt` → `compact`），Enter 执行选中命令，Tab 仅补全。`@file` 支持有界异步文件检索和选择插入，匹配结果优先显示路径层级较少的文件，同层级按最近修改时间排序，时间相同时按匹配度排序，含空格路径自动引用；目录列表末尾提供 `../` 返回上级（空目录也可用），Tab/Enter 进入所选目录或插入文件；输入 `@./` 可仅浏览当前目录。选择文件不会提交提示或读取上传文件内容。
- `/delete` 直接确认删除当前会话，无需进入会话列表；确认后先停止该会话进程，再永久删除其历史文件，仅删除当前会话、不级联删除父子分支。Esc 取消；运行中的任务、草稿与附件会在确认后丢弃。删除最后一个标签会新建空白会话；其他标签及历史不受影响。命令不接受目标参数。
- `/close` 确认后停止当前进程，历史仍保留；`/quit` 退出并回收全部子进程。并行会话仅在前端运行期间持续工作，退出不保留后台守护进程。

所有上述 UI 都在 `pi-goui/` 内实现，**不依赖 `extensions/ui/`**；可按计划注释该扩展。启动不会安装辅助扩展、复制鉴权或主动改写原配置。正常提交仍会调用 pi 的模型与工具，权限与费用规则不变。

## 快捷键与配置

读取 `${PI_CODING_AGENT_DIR:-~/.pi/agent}/keybindings.json`、全局 `settings.json` 及项目 `.pi/settings.json`。按动作覆盖默认绑定；空数组禁用该动作。`/hotkeys` 按输入、对话导航、搜索、会话选择器、菜单和编辑器分组显示绑定，并注明作用条件与优先级；不列出未实现的树编辑/过滤或模型批量管理动作。`/reload` 重新读取前端配置。

| 默认键 | 行为 |
| --- | --- |
| Enter / Shift+Enter | 提交 / 换行（Ctrl+J 也可换行） |
| Escape | 中止当前任务；空闲双击打开树 |
| Ctrl+C | 清空输入；空输入时双击退出整个前端 |
| Ctrl+D | 空输入关闭当前会话；最后一个会话关闭后退出，运行中的会话先确认。非空输入保持向前删除 |
| Shift+Tab | 循环思考强度 |
| Ctrl+N | 新建会话 |
| Ctrl+↑ / Ctrl+↓ | 上一个 / 下一个已打开会话（循环切换） |
| Ctrl+Shift+↑ / Ctrl+Shift+↓ | 上一条 / 下一条用户消息 |
| Ctrl+P / Ctrl+Shift+P | 下一个 / 上一个模型 |
| Ctrl+L | 模型选择 |
| Ctrl+T | 显示或隐藏思考 |
| Alt+Enter / Alt+Up | 运行中追加 follow-up / 恢复排队文本到编辑器 |
| Ctrl+G / Ctrl+X | 外部编辑器 / 复制最近助手回复 |
| PageUp / PageDown | 聊天滚动 |
| Ctrl+Home / Ctrl+End | 最早消息 / 最新消息并跟随 |

本机配置 `{"app.session.resume":["ctrl+y"]}` 会让 **Ctrl+Y 打开恢复会话面板**，优先于默认 yank。增强组合键依赖终端支持 CSI-u / Kitty 等协议；不支持时可配置其他绑定。`Ctrl+S` 是用户显式保存默认思考强度，会更新原 `settings.json`；不会在启动时自动保存。

图片粘贴会在光标处插入蓝色、无下划线的 `[image1]`、`[image2]`，与文字一起显示在同一条用户消息中。删除标记后对应图片不发送；发送时按引用顺序排列附件并统一编号。读取剪贴板期间不会提前提交，继续输入也保留原粘贴位置。`/attach path/to/image.png` 同样插入图片标记，`/detach` 清除待发送附件。Linux 图片剪贴板使用已有的 `wl-paste` / `xclip`，前端不自动安装工具。

发送后点击图片标记可通过系统图片查看器打开保存的原图（Linux `xdg-open`、macOS `open`，需要桌面环境）；拖选复制不会打开。只从消息数据生成经过格式校验的私有临时图片，不重新读取原文件，也不上传网络。退出前端会清理临时图片，但不会关闭已打开的查看器窗口；其他平台暂不支持。极窄终端中折行拆开的标记不提供点击区域。

## 启动更新通知与 Pi 变更内容

- 启动后异步检查一次所选 `--pi` / `PI_BIN` 对应的 Pi 和全局设置声明的非固定版本外部 npm/Git 包；使用该安装自身的只读 API，约 20 秒超时，不加载扩展、不调用模型、不安装包或写入设置。本地路径扩展、项目包不在检查范围内。
- 有更新时，在聊天区默认欢迎内容下方提示。没有更新、网络失败或安装不兼容时保持安静，不阻碍使用；没有提示不保证全部最新。**只有通知，没有手动检查命令、确认弹窗或升级执行流程。**
- Pi 版本改变后，首次启动在同一区域展示所选安装 `CHANGELOG.md` 中的当前版本内容，可用聊天滚动查看全文；首次使用也展示一次。不读取扩展变更内容，不联网获取 changelog。文件缺失或没有当前版本章节时不显示。
- 展示后，将 Pi 版本记录在系统用户缓存目录的 `pi-goui/` 下，后续启动不重复提示该版本的变更内容；不写入 Pi 设置、会话历史或模型上下文。恢复历史时不覆盖原聊天；打开空白会话后才展示并记录。开始聊天后，默认欢迎内容及启动信息让位于真实消息。
- 任何非空 `PI_OFFLINE`（通常设为 `1`）或转发的 `-- --offline` 跳过联网检查，本地变更内容仍可显示。`--check` 仍仅检查 RPC；`run.sh` 仍只构建本地前端，不拉取仓库代码。

## RPC 边界

快捷键采用原生动作名称及配置，但**不宣称完整原生交互界面功能对等**：

- 支持 RPC 的 select、confirm、input、editor、通知、文本状态与 widget。TypeScript 自定义 TUI、header/footer/editor 组件、Worker 专用面板不能直接复用。
- `/tree` 当前只读浏览，不提供原地树导航、过滤与标签编辑；不注册这些未实现动作的快捷键。
- 会话选择器中的 `app.session.delete` 使用 Ctrl+D 或 Ctrl+Backspace，均需确认；旧 `deleteSessionNoninvasive` / `app.session.deleteNoninvasive` 配置兼容映射到该动作，显式配置 `app.session.delete` 时优先使用后者。
- 分叉：悬停聊天中的用户消息标题，点击“从此轮分叉”；也可用 `/fork`，按最新在前的轮次、问题与回复摘要选择。选中后直接创建独立会话并打开新标签，不再预览或二次确认。分支包含所选轮的回复及工具结果，不包含下一轮；原会话、草稿及运行任务保留。非最后一条用户消息，只要该轮助手已成功完成回复（包括正常达到长度限制）且工具调用全部结束，即使当前会话还在运行也可分叉；最后一条用户消息仍要求整个会话空闲。失败、中止、仅有工具调用或尚无回复的历史轮次不视为已完成；无法校验历史一致性时会拒绝并提示刷新重试。新分支默认沿用原会话显示名称，不添加 `fork from` 前缀；列表以缩进和 `↳` 区分父子关系，不把符号写入名称。
- 分支来源：聊天顶部显示“来自… · 第 N 轮”，点击该行或使用 `/origin` 查看来源；优先复用已打开的标签，必要时打开独立标签，历史加载后滚动到原用户消息。只滚动，不改变源会话的树位置；目标不在当前活动分支时会提示。旧分支只有原生 `parentSession` 时仍可打开来源，但不猜测轮次。源文件缺失、符号链接或会话 ID 不符时拒绝导航；异步期间切换标签不会被迟到结果抢回焦点。
- 会话列表：`/resume` 与侧栏 **RECENTS** 默认直接展示父子关系，无需打开独立分支视图。家族及同级子会话按最近活动排序，父会话先于后代；缩进有上限，不绘制精确树形图。`/resume` 搜索时按名称、首条消息或路径匹配，结果平铺；名称过滤或当前目录范围内缺少父会话时，子会话作为根行显示。旧文件的 `parentSession` 同样可用，身份不符、自指及循环关系会断开，且不丢失可选会话。侧栏不再显示“关联分支”行或计数。
- `/resume` 保留当前会话并标记 `[current]`，不会因隐藏中间节点而截断多层关系；每次打开重新读取会话文件，最新父子关系优先于已打开标签的旧缓存，分叉后无需重启。已移除额外的 `/branches`、`/branch-tree` 命令；不提供分支合并、原地回退或拖动编辑。
- 新分支在 v3 文件头保留 `parentSession`，并写入可选 `piGouiFork: {version: 1, sourceId, userEntryId, cutoffEntryId, turn}`，记录直接父会话、所选用户消息及保留范围末条目。此元数据不进入消息或模型上下文；嵌套分叉记录直接父关系，重启仍可读取。
- `/reload` 只重载前端配置；更改 pi 扩展后需重新打开会话。
- `/theme` 打开主题选择器，也可使用 `/theme nord` 直接切换。预设包含 `pi`、`catppuccin`、`tokyo-night`、`nord`、`rose-pine`，即时应用于所有会话，并保存到 agent 配置目录的 `goui.json`，重启和 `/reload` 后保留；不修改原生 pi 设置。上下选择、翻页、滚轮或筛选时同步预览正文与边框配色；Enter 保存，Esc 恢复原主题。透明背景保持不变。
- 不提供完整 scoped-models 管理，以及直接的 `/login`、`/logout`、`/settings` 编辑界面；这些操作使用原生 `pi`。
- 工具图片目前显示附件信息，不提供内联像素预览；超过 256 KiB 的源码保留全文，但不做语法高亮。
- 主题、编辑器与布局不保证逐项复刻原生所有设置。单词移动采用 Unicode 分词，中文、泰文等语言的停靠点可能与 Node/ICU 词典分词不同，但不会拆断字素。扩展的任意自定义组件及复杂 widget 布局仍受 RPC 协议限制。

## 代码结构

`internal/` 按职责分包，内聚且有独立接口的功能继续下沉，不要求所有实现平铺：

```text
internal/
├── session/worker/    # Worker 录制读取、事件合并与只读回放
├── render/frame/     # 边框几何、角色配色和渐变
├── render/tooldetail/ # 各类工具的完整详情
└── ui/imagepreview/  # 图片校验、私有缓存、查看器与资源清理
```

`session` 保留通用会话投影，`render` 保留组件布局，`ui` 保留 Model 事件路由与交互状态；不为分目录暴露内部状态或增加透传包装。模块边界与依赖方向见 [DESIGN.md](DESIGN.md)。

## 验证

```bash
cd pi-goui
go test -race ./...
go vet ./...
python3 script/test-ui.py
# 可选：真实 pi 只读白名单代理；禁用扩展、临时 HOME，不允许模型/工具命令
python3 script/test-ui.py --real-pi "$(command -v pi)"
# 单独运行真实只读检查（不替代上面的假 RPC PTY 验收）
python3 script/test-ui.py --real-only --real-pi "$(command -v pi)"
```

PTY 脚本自动构建临时二进制，使用隔离 HOME 与假 RPC，检查多会话进程/草稿/对话框隔离、压缩前历史、单行压缩、快捷键、分组及单项工具框、Unicode 鼠标复制、回到最新、点击模型/强度、首次换行与边框对齐、单会话关闭、尺寸变化与退出回收。`tests/real_rpc_guard.py` 只转发六类只读查询，拒绝 prompt、steer、follow_up、compact、bash 等操作。测试失败会报告屏幕与 wire 记录，不能据此视为验收通过。
