# pi-goui

[English](README_EN.md)

独立的 Go 前端，提供 Bubble Tea TUI 和极简浏览器 WebUI，通过标准 Pi RPC 复用 Pi 的模型、工具、认证和扩展。可复制整个 `pi-goui/` 构建，也可只分发二进制；运行不依赖本仓库的其他目录或作者配置。

## 构建与启动

构建需要 Go 1.26+；运行需要已安装并完成认证的 Pi / Node.js。在本目录执行：

```sh
go build -trimpath -o bin/pi-goui ./cmd/pi-goui
./bin/pi-goui --cwd /path/to/project
./bin/pi-goui --check
```

也可用 `./run.sh` 构建并启动。Unix 上桌面默认自动提供私有本机同步入口，**立即进入 TUI，不打印二维码、不启动 TCP 网页监听器**；WebUI 必须单独启动，先后顺序不限。用 `--share=false` 可禁用此入口；不支持的平台保持普通桌面模式。常用选项：

| 选项 | 用途 |
| --- | --- |
| `--pi /path/to/pi` / `PI_BIN` | 指定 Pi 可执行文件，默认从 PATH 查找 |
| `PI_CODING_AGENT_DIR` | 指定 agent 目录，默认 `~/.pi/agent` |
| `--continue` / `-c`、`--session file.jsonl` | 恢复当前目录最近会话，或打开指定会话 |
| `--no-session` | 不持久化会话，不能与恢复选项同时使用 |
| `--check` | 检查 RPC 启动，不发送提示词或保存会话 |
| `--share=false` | 禁用桌面的自动发现/同步入口；默认自动启用，无需传 `--share` |
| `-- --model provider/model --no-extensions` | 向 Pi 转发选项；不允许覆盖 RPC 模式、会话归属或传入位置提示词 |

在原生 `pi` 中完成登录，不复制他人的认证或设置。启动前端不会自动安装扩展或调用模型；**提交提示词仍使用 Pi 的正常权限并可能产生费用，本程序不是沙箱。**

## 浏览器与局域网 WebUI

独立入口 `cmd/webui` 在真实 PTY 中直接运行同一个 Bubble Tea TUI，通过 WebSocket 将输入、输出和尺寸同步到浏览器内的 xterm.js；不是另一套聊天页面。TUI、网页资源均包含在同一个二进制中，不需要额外安装 `pi-goui`、npm 构建或 CDN。Web 终端支持 Linux/macOS 等 Unix 系统，并使用系统 `/bin/ps` 枚举与回收独立后端进程组；Windows 请在 WSL 中运行。以下命令在本目录执行：

```sh
go run ./cmd/webui --cwd /path/to/project
# 或构建独立二进制
go build -trimpath -o bin/webui ./cmd/webui
./bin/webui --check
./bin/webui --listen :8888 --key 'my-lan-key' --cwd /path/to/project
```

默认只监听 `127.0.0.1:8888`。WebUI 启动时输出登录 token（未指定时随机生成）、带 `?pk=token` 的登录链接及终端二维码；扫码或打开链接会自动登录，页面读取后立即移除地址栏中的 `pk`，不存入 localStorage。仍可打开普通地址手动输入 token。**手机访问请显式使用 `--listen :8888`**；通配监听时会选择活动网卡的局域网 IPv4 和实际端口生成二维码，默认回环监听的二维码只能在本机使用。多网卡环境请确认链接 IP 与手机互通。

可通过 `--key 'my-lan-key'` 固定登录口令；原有 `--token` 别名和 `PI_WEBUI_TOKEN` 环境变量仍可使用，推荐环境变量以避免 shell 历史记录。token、登录链接及二维码都是服务访问凭据，不是模型 API key，不要分享或公开截图；链接仍可能留在聊天记录、代理日志等位置。

| WebUI 选项 | 用途 |
| --- | --- |
| `--listen host:port` | 监听地址，默认仅回环 |
| `--key value` / `--token value` | 固定登录口令；未指定时使用 `PI_WEBUI_TOKEN`，仍为空则随机生成 |
| `--pi`、`--cwd`、`--agent-dir` | Pi 可执行文件、默认项目目录及 agent 目录；目录参数相对启动目录解析 |
| `--session file.jsonl` / `--no-session` | 初始恢复会话或禁用持久化，不能同时使用 |
| `--request-timeout 30s` | 只读 `--check` 的 RPC 请求超时 |
| `--tls-cert cert.pem --tls-key key.pem` | 启用 HTTPS，证书与密钥必须成对提供 |
| `--check` | 禁用持久化，只查询 `get_state` / `get_entries` 后退出；不提交模型或工具操作 |
| `-- --model provider/model --no-extensions` | 转发与 TUI 相同的安全启动选项，不允许覆盖 RPC/会话归属 |

登录和刷新后先显示**实例选择页**，不会自动启动或连接 TUI；停留该页时自动刷新，桌面后来启动或退出也会更新。点击“桌面共享实例”可与桌面同时查看和操作同一 TUI；其他已有实例也可继续连接。“新建实例”先进入目录选择页，再创建**独立 TUI**，不会关闭或抢占桌面及其他实例。显式 `--session` 只作用于原默认实例，新建实例即使选相同目录也不会复用该历史文件；独立 `webui --session …` 会提供默认实例入口。

目录列表只读原生会话头部，结合本次服务中最近选择的目录，去重后最多显示 **10 个现存目录**；不足十个不补假数据，缺少历史时使用启动 `--cwd`。也可输入服务器上的其他绝对路径；读取列表不会改写原生历史或 Pi 设置。

页面和终端统一内嵌 JetBrainsMono Nerd Font Mono 3.5.1（常规、粗体、斜体、粗斜体），中文回退使用本机系统的文泉驿等宽微米黑；浏览设备无需安装字体。字体加载完毕后才初始化终端，并同步 Go TUI 的宽字符/Emoji 列宽规则，避免字体切换或组合 Emoji 导致边框错位。手机点击消息、工具或底栏不会主动唤起输入法，点击终端编辑区才开启软键盘。单指在消息、列表或详情内上下滑动会转成原 TUI 的滚轮事件，滚动触摸起点所在区域；滑动不触发选项点击或唤起输入法，普通轻点仍可选择。

终端铺满页面，左上角悬浮图标点击展开连接状态、重连、复制/粘贴、重启、“返回实例列表”、“关闭实例 / 换目录”和退出登录；菜单不占用布局空间，点击外部或按 Esc 收起。网页与终端空白区域统一使用深蓝灰底色。布局、会话标签、斜杠命令、工具详情、问卷及 Worker 面板均直接复用原 TUI；后文的使用说明也适用于网页终端。每个实例有自己的 TUI；独立 TUI 打开同一 session 时共享后端（见下文），多个网页与桌面可同时连接，广播同一份输出，输入进入同一后端，不再踢掉其他连接。草稿、光标、会话切换及滚动状态也是共享的；多端同时打字可能混在一起，不提供独立编辑锁。浏览器保留的快捷键可能无法传给终端，可改用对应斜杠命令。

关闭网页、退出网页登录或断线不会终止任务。切入后台时网页释放连接，回到前台或网络恢复后重新连接原实例；服务器心跳清理失联连接，不停止 TUI。即使浏览器被系统强杀、没有机会发送退出通知，后台任务也继续；全部网页断开后桌面始终仍可操作，无需归还权限。刷新后重新选择当前实例可继续原 TUI，断线重连不要求重选；草稿和待答对话仍在服务进程内。菜单“返回实例列表”仅断开本页连接，任务继续；“关闭实例 / 换目录”会退出所选 TUI，再返回新建实例的目录页，不影响其他实例；仍有其他独立 TUI 使用的共享 session 后端会继续运行。旧页面不能自动重连复活已删除的实例。终端输出只保留有界回放缓存，完整历史仍由 Pi 保存；不是永久终端录像。`/quit` 退出 TUI 后不会自动重启，可点击“重启 TUI”显式重新启动；该按钮会退出原 TUI 并释放其会话连接。停止 WebUI 服务只回收它创建的独立 TUI，并断开代理连接；其他 TUI 仍使用的共享后端和被发现的桌面实例继续运行，重启 WebUI 后仍可找到桌面。不要让不参与共享协议的原生 Pi 或旧版 goui 同时写入同一历史文件。

复制/粘贴使用悬浮菜单按钮或 `Ctrl+Shift+C/V`；TUI 发出的复制请求须经用户操作才写入浏览器剪贴板。局域网 HTTP 通常不提供 Clipboard API，页面会使用复制降级或手动粘贴框。图片文件路径、外部编辑器及打开文件等操作仍作用于服务器，不等同于浏览器本地桌面能力。

**局域网不等于可信网络：认证用户能以服务进程的宿主权限运行 Pi 工具，本服务不是沙箱，也不是多用户权限隔离系统。** 默认 HTTP 不加密 token、消息和工具结果；在不可信网络使用 HTTPS 或可信安全隧道，不要直接暴露到公网。不会自动安装扩展、复制凭据或修改 Pi 设置；按 `Ctrl+C` / `SIGTERM` 退出服务。

### 桌面与多个网页同步同一实例

分别在两个终端运行，**顺序不限**：

```sh
# 桌面：直接进入 TUI，不显示二维码
./run.sh --cwd /path/to/project
# WebUI：单独启动；手机访问时显式开放局域网
./bin/webui --listen :8888
```

WebUI 自动发现**同一系统用户、同一 agent 目录**下运行的 goui；多个桌面分别列出，点击才连接；已有连接不会被替换。桌面以私有 Unix socket 注册本机入口（目录 `0700`、注册文件/socket `0600`），不占用 8888 或其他 TCP 端口，也不依赖 WebUI 存活。注册表固定放在 `~/.pi/goui-instances/`（不放进 agent 目录），登记内容记录所属 agent 目录用于隔离发现，不复制模型凭据或修改原生 Pi 设置；正常退出清理自身注册，离线残留不列为可用实例。不同 agent 目录不会互相发现，需让桌面的 `PI_CODING_AGENT_DIR` 与 WebUI 的 `--agent-dir` 一致。

旧版共享执行者不会因重建程序、新开窗口或刷新网页而热升级，也无法补造它未记录的当前轮统计。升级时先等任务正常结束，再正常退出使用该会话的所有旧实例，由新版重新创建执行者；不要为显示统计而中断运行中的任务。

登录链接和二维码**只在独立 WebUI** 输出；桌面不再接受 `--listen` / `--token`。不需要 tmux；旧版本或 `--share=false` 启动的桌面无法事后接入，需重新以当前默认方式启动。

- 在桌面按 **Ctrl+]** 可暂时脱离显示，后台任务继续；按 Enter 接回，不输出二维码。
- 桌面和任意数量的网页连接同一个实例时，始终可同时查看和操作，无接管弹窗。打开或关闭网页不停止实例；重启、关闭实例和 `/quit` 属于显式操作，会影响该实例的所有连接端。
- **独立实例同步 working 统计**：在任务运行中打开同一原生会话，新 TUI/网页实例继承该轮的 turns、输入/输出 token（含已配置能力的用量）、TPS 和原始开始时间，而非只显示 `working` 或重新计时。结束后统计冻结，下一轮重新累计；本地草稿和显示偏好不受影响。
- **最近查看/操作端决定共享尺寸**：新网页连接实例时使用其尺寸；之后任一端的键盘、鼠标或触摸操作切换为该端尺寸。其他端同步到相同网格；网页小屏可滚动查看超出屏幕的部分。被动窗口变化只更新该端期望尺寸，只有当前活动端的变化会立即重排；输出、终端自动回复和心跳不抢尺寸。活动端断开后回到上一在线活动端。纯网页实例也遵循同样规则。
- 桌面始终属于原共享实例，网页新建的独立实例不会改变桌面目录。若网页显式关闭桌面共享实例，桌面按 Enter 会重新打开原启动目录。
- 桌面宿主绑定其前台进程生命周期，不是后台守护进程；关闭桌面会释放其 TUI 连接，不停止独立 WebUI 或其独立实例。同一 session 仍有其他独立 TUI 使用时后端继续运行，最后一个 TUI 离开才回收。在脱离提示中按 Ctrl+C 或发送 SIGTERM 停止；桌面连接 TUI 时 `/quit` 也会退出桌面宿主。`--check` 只做只读检查，不注册实例或启动监听器。

## 使用与配置

标签切换保留草稿、队列、弹窗和运行任务；同一 TUI 重复打开 session 会定位已有标签。在 Unix 上，同用户、同 canonical agent 目录的多个独立 goui（含 Web 派生 TUI）打开同一原生 session 时，复用一个稳定会话执行者和 Pi 进程；不同 session 仍各自独立。非 Unix 平台保留每个 TUI 独立后端，不提供此跨进程共享能力。

恢复历史会话会先在后台读取本地原生记录供浏览，同时连接后端，不再等待 Pi 启动完成才显示正文。侧栏候选、悬停项与恢复列表选中项会有界地预读本地历史，命中后不再重复解析，也不会提前启动 Pi；文件变化会使预读失效。冷预览直接解析 JSONL，避免先拼成大段 RPC JSON 再解析；首次打开仍有实际读取成本。初始共享握手不会重复拉取整份历史；统计和命令列表在正文提交后补充，不阻塞正文载入，也不会使已就绪或正在后台布局的正文失效。未变化的快照解析与历史文件校验会复用缓存，文件或会话内容改变后重新检查。连接期间可以输入；首次回车会暂存原输入及附件，取得权威状态并通过必要的历史校验后只提交一次，之后输入的草稿独立保留。暂存期间再次回车不会覆盖首次发送。真正连接失败会明确提示并保留历史及未发送内容，不以 `stopped` 代替原因，也不会自动重发结果未知的操作。

### 同一终端镜像与独立会话共享

- 桌面和网页连接**同一 TUI**时，是同一个终端的镜像：草稿、光标、标签和尺寸全部同步。多个**独立 TUI**打开同一 session 时，只同步消息、运行状态、模型/思考级别、队列、会话名称和扩展业务状态；草稿、附件、标签和布局各自保留。任一端的发送、排队或停止操作都会影响该共享会话。
- 问卷广播给各端，首个成功写入后端的回答关闭各端问卷；失败保留可重试。晚加入者补齐待答交互和持久 status/widget/title，编辑器填充不作为共享持久状态回放。合并队列与提交由执行者串行处理，避免两端交错清空队列。
- 实际 TUI 自动选举协调者，桌面外层宿主、纯 Web 服务和执行者不参选。协调者正常退出或被强杀时，由其他 TUI 换届；它们直连稳定执行者，因此换届不改变 Pi PID、不重发操作。暂停（SIGSTOP）不会因超时被抢锁。浏览器断线不退出隐藏 TUI；最后一个 TUI 离开且无文件操作租约时才回收后端。
- 正在被另一 TUI 使用的 session 不允许直接删除或改写文件；文件操作使用独占租约。不要让原生 `pi`、旧版 goui 或其他程序同时写入同一 session，它们不参与此协调协议。
- 协调元数据位于 `~/.pi/goui-rpc/<agent目录哈希>/`，按规范化后的 agent 目录计算 SHA-256 分组；不同 agent 隔离，同一目录的符号链接别名复用，不在 agent 目录内创建运行状态。未知启动结果、缺失所有权信息或仍存活的旧 writer 会导致安全拒绝，而非另起第二 writer；未知结果不自动重发，本地草稿供人工检查恢复。执行者自身崩溃**不承诺无损接管**。不要删除运行中的注册信息或锁文件来强行恢复；须先核实相关进程和会话文件。升级不会迁移旧进程。若旧的 `<agent目录>/goui-rpc` 仍存在，新版会安全拒绝启动（即使旧目录为空），不自动移动、删除或改写它；请确认旧实例及其 Pi 后端已全部退出后，自行处理旧目录再启动新版，不要混跑新旧版本。

| 命令 | 用途 |
| --- | --- |
| `/new`、`/resume`、`/sessions` | 新建或浏览会话 |
| `/model`、`/thinking` | 选择模型或思考强度 |
| `/fork`、`/origin`、`/tree` | 分叉、查看来源或只读浏览会话树 |
| `/attach` | 附加图片 |
| `/theme`、`/reload` | 选择前端主题、重载前端配置 |
| `/hotkeys` | 查看当前有效快捷键及适用条件 |
| `/close`、`/delete`、`/quit` | 关闭当前会话、确认后永久删除、退出全部会话 |

- 默认 `Enter` 提交、`Shift+Enter` / `Ctrl+J` 换行；`Esc` 中止任务；`Ctrl+N` 新建会话，`Ctrl+↑/↓` 切换标签，`Ctrl+L` 选模型，`Ctrl+T` 切换思考展示，`Ctrl+End` 回到最新。
- `Ctrl+C` 清空输入，空输入时双击退出；`Ctrl+D` 在空输入时关闭当前会话，运行中先确认。关闭最后一个会话会退出前端。
- 点击工具展开预览，使用“查看 ↗”打开完整详情；详情可独立滚动、选择复制和调宽，`Esc` 关闭。预览截断不改变保存记录；估算 token 不是计费 usage。
- 会话选择器中 `Ctrl+R` 重命名、`Ctrl+D` 删除并确认。悬停用户消息标题，点击“从此轮fork”直接新建独立会话，保留原标签与任务；`/tree` 不提供树编辑。
- 读取 agent 目录的 `keybindings.json`、`settings.json` 及项目 `.pi/settings.json`；键位覆盖默认值，空数组禁用动作。增强组合键取决于终端支持。
- `/theme` 预览主题，Enter 保存、Esc 恢复；主题偏好写入 agent 目录的 `goui.json`，不改原生 Pi 主题设置。缺少主题文件时使用内嵌默认值；`/reload` 不重载后端扩展。

本前端不承诺原生 TUI 功能完全对等：认证、完整模型范围管理及原生设置编辑请使用 `pi`。

## 可选扩展

未安装任何第三方扩展时，普通 Pi 工具、codemode 和通用结果展示仍可用。已有适配支持问卷、Worker、Codex 档位及 SoL-Pi/Web 结果；安装方式以各扩展自身文档为准，Go 不直接加载 TypeScript。

Worker 完整记录通过后端能力只读获取，关闭查看器不会停止任务；不可用时显示已有任务结果，已有部分记录会保留并标记不完整。Codex 档位控件仅在桥与能力可用时显示。接入说明见[扩展指南](internal/extensions/README.md)。

## 启动更新通知与 Pi 变更内容

启动后异步只读检查所选 Pi 和全局配置声明的非固定版本 npm/Git 包；不安装或升级，不调用模型，不写入 Pi 设置。无更新、网络失败或安装不兼容时保持安静，没有提示不保证全部最新。

任何非空 `PI_OFFLINE` 或转发的 `-- --offline` 跳过联网检查；本地 Pi 变更内容仍可显示，已展示版本只记录在前端独立缓存中。`--check` 仅检查 RPC，`run.sh` 只构建本地前端。

## 代码结构

- [cmd/pi-goui/](cmd/pi-goui/)：TUI 启动；[cmd/webui/](cmd/webui/)：WebUI 启动。
- [internal/core/](internal/core/)：通用配置、会话投影、输入、渲染及 UI；`extension/` 定义接入契约，`extensionapi/` 提供低层投影与绘制接口。
- [internal/runtime/](internal/runtime/)：RPC 传输、跨进程身份/协调者选举、稳定会话执行者、提交/文件租约与桌面发现；不依赖 core 或 extensions。
- [internal/extensions/](internal/extensions/)：第三方协议、状态、UI 和渲染；集中返回接口列表，由 core 组合后使用。

`internal/` 顶层只保留 `core/`、`extensions/` 和 `runtime/`。设计与扩展契约见[扩展指南](internal/extensions/README.md)，修改约束见 [AGENTS.md](AGENTS.md)。

## 响应与回放边界

Worker 记录的历史解析与事件重放在后台独占副本上完成，结果仅提交给原查看器；损坏的历史或 reset 保留已读内容并标记不完整，后续完成记录不能掩盖错误。Web 终端回放保留最近 4 MiB 和最多 16 个尺寸段，底层复用缓冲最多 8 MiB（不含连接发送队列）；滑动窗口避免每块输出搬移全部历史。回放缓存不是会话存档，不截断原生记录。

## 验证

测试命令及隔离要求见 [AGENTS.md](AGENTS.md#验证)。假 RPC 夹具自身可用 `PYTHONDONTWRITEBYTECODE=1 python3 tests/test_fake_rpc.py` 验证；配套扩展完整回归见[扩展总览](../extensions/README.md#更新卸载与维护)。默认使用假 RPC；可选真实 RPC 检查必须经只读白名单代理，不允许模型或工具调用。测试结果不等同于真实终端或跨平台验收。

Linux 上 `python3 script/test-resume.py` 覆盖慢连接预览、首次发送暂存、空白会话恢复、双标签草稿及连接失败，并测量约 17 MB 历史的冷首屏与预读后的侧栏鼠标点击首屏。可用 `python3 script/test-shared-session.py` 验证真实双 TUI、唯一后端、SIGSTOP/SIGKILL/正常换届、草稿隔离、运行中晚加入的 working 统计/计时、问卷与回收；`python3 script/test-shared-web.py` 验证完整 HTTP/WS 入口、Web 子 TUI 参选、桌面运行中启动 Web 的 working 统计同步、断线保活和跨入口退出隔离。这些脚本临时构建、隔离 HOME/agent/cwd，仅运行假 RPC；它们不代替真实模型、实体手机或其他系统的实机验收。

WebUI 还可运行无依赖的 JS 测试；设置 `CHROME_BIN` 可启用真实无头 Chromium 终端交互测试（模拟 WebSocket，不调用模型）：

```sh
node --test internal/core/web/assets/*.test.mjs
```
