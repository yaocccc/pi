# 展示模块

[English](README_EN.md)

`frame/` 通过 `Border`、`Box`、`Gradient` 和 `Palette` 提供角色配色、主题预设及 ANSI 安全的边框/渐变几何。本包和 UI 组件都直接使用它；它不依赖父包。边框算法测试放在该子包，会话正文/侧栏集成与点击几何测试留在本包。`tooldetail/` 负责通用及原生工具的完整详情宿主。第三方卡片和详情实现在 [`../extensions/toolrender/`](../extensions/toolrender/)，通过 `extensionapi/render.go` 提供的逐次渲染回调接入；`extensions.go` 和 `tooldetail/extensions.go` 只做薄宿主绑定。`tooldata/` 提供保留数字精度的共享 JSON 解码。通用组件布局与其几何计算保持在一起，第三方策略则留在适配器包中。

`Transcript` 渲染不可变的 `[]session.Item`。用户消息使用窄幅右对齐气泡，标题为 `你`；连续的助手/思考/工具记录共用左侧气泡，标题取 `Options.AssistantTitle`，缺省为 `助手`。系统、压缩及分支摘要使用 `系统` 边框，仅展示一条裁剪后的概要；完整保存文本仍保留在投影中。相邻消息框之间不额外插入空行，Markdown 段落保留自身间距。

用户文本和图片块投影到同一个气泡。编号引用 `[imageN]` 只有对应已保存的 `Item.Images` 时才以无下划线的蓝色显示；`Document.ImageLinks` 提供从零开始的消息/图片索引及终端行、单元格点击范围。UI 按该会话保存的图片字节解析点击。缓存键只使用图片数量，不使用 base64 数据；缓存链接与内容块应用相同的分区偏移。极窄行中换行后不完整的引用不支持点击。

角色边框颜色编译自参考 UI 的调色板：用户为薄荷色，助手为蓝色，系统/编辑器为紫色，工具为中性色。除选中的侧栏卡片（`82;85;88`）外，背景均透明。Markdown 使用 Glamour，工具源码使用 Chroma。不可信控制字符在渲染前移除；ANSI 感知换行支持 Unicode 和窄宽度。

每组工具执行（即使只有一次调用，显示 `1 calls`）默认折叠为 `tool-group:<first ID>`。整个工具组与前后正文各隔一行，而不是在组标题和子项之间留空行；位于气泡首尾的组不额外增加边界空行。展开后子项缩进两个单元格，并相应减少可用宽度。`Options.ExpandTools` 展开组/卡片，显式 `Options.Expanded[id]` 可双向覆盖它。Worker 任务自身始终展开，不接受单任务折叠项。点击处理切换 `!Block.Expanded`，而不是对可能缺失的 map 项取反。繁忙会话启用 `ShowToolActivity` 时，最后一个尚无后续助手正文的组，会在保留原有基础颜色的完整 calls 标题上播放前景高亮扫过动画，包括调用数量、失败数和 token 估算；不另加 Running 标题。下方显示最近三次调用的缩进摘要或完整 Worker 卡片。已完成 Worker 仅在这三项之内保持展示，更早的 Worker 与其他工具一样省略。这并不等于展开完整工具结果。活动列表紧接组标题，不插空行；条目使用正常工具布局、点击目标和逐工具折叠状态，因此无需打开组即可展开/折叠普通工具。活动期间，折叠组显示最近调用预览，展开组显示全部调用且不重复预览，两种状态都对活动组标签播放动画。正文、会话边界或空闲状态会移除该活动展示。缓存失效条件包含活动组身份，也覆盖后续分区结束其生命周期的情况。

Read 保留紧凑的路径/参数行，并展示最多八个终端行的已保存源码及原始行号，必要时显示截断标记。Edit/write 卡片仅包含记录中的 diff；若未保存 diff，则明确标记为替换/写入预览，失败时保留错误消息。它们省略参数/结果分区，并按可见内容收缩。Codemode 展示高亮 JavaScript 与实际内部调用。Worker 优先使用原生 `details` 快照，任务行不可折叠，展示状态、预设、目标、真实用量/耗时和结果摘要，隐藏模型/provider 与会话模式。目标和结论之间的不可交互步骤区按快照顺序合并工具与思考，仅显示最近三步。思考使用 `!` 标识，移除粗体标记并拆分连续标题，不在列表下方重复显示。区标题为 `≡ Activity`，不含总数；省略项显示 `… n items (已折叠)`。总数由已报告工具调用与保留的思考条目组成，不猜测已丢弃的思考历史。Worker 步骤标题不显示结果计数或 token 用量；普通 calls 组只显示非零失败数，不显示成功数。结论展示保持不变，尚无结论时按顺序展示说明文本，排除槽位状态噪声。运行中和已完成 Worker 均保留在 calls 组内。Worker 组和批次卡片遵循普通的显式/全局展开设置，不因运行状态自动展开。外层组折叠时只渲染标题，不受子项或全局展开状态影响。缺失元数据不伪造；历史 JSON 和纯文本结果有结构化兜底。预览不读取当前磁盘文件，也不执行任何操作。

Bash 卡片显示无行号命令、无分区标题的可选参数，以及原样输出的前八个终端行（无输出时显示 `(no output)`）；较长输出以截断标记结束。边框按可见内容收缩，完整输出仍保留在会话数据中。问卷卡片展示问题文本和单份选项列表，高亮已选答案，支持自定义回答、多问题、多选、等待及取消状态，不重复结果/元数据分区。搜索/列表工具与未知/MCP 工具使用一行暗色参数摘要和最多八个终端行的结构化或原样结果；省略 Parameters/Result/Metadata 标题和额外元数据，标记截断，并按可见内容收缩。JSON 对象使用带标签字段；两个及以上记录组成的同构数组，在所有标量值均能容纳时使用列顺序确定的对齐表格。窄屏、稀疏、嵌套、多行及含源码/附件的记录回退到完整字段视图，不裁剪字段值。无效 JSON 按原文展示。折叠预览提供有用的字段值/集合数量，而不只是字段数；多行文本显示行数，并区分空结果和等待输出。失败的 edit/write 预览实际错误，而不是请求的变更。图片字节不进入这些表格或摘要。Bash、read 和通用预览即使展开也有界限，完整保存数据仍保留在会话内。其他既有展开控件展示已保存输出，不引入新磁盘读取或分页状态。

`Document.Blocks` 使用从零开始、左闭右开的终端行偏移，包含边框和有意保留的组间距。组块只覆盖摘要行。普通工具块覆盖调用/结果；Worker 仅批次标题可折叠，任务内容范围不可折叠，点击任务不会切换父项。隐藏子项没有块。UI 加上视口起点并减去滚动偏移。

`State.MessageCount` 和 `Item.MessageIndex` 描述当前完整分支中的原生消息，与终端行、内容块及折叠无关；它们传递到 `Document.MessageCount` / `Block.MessageIndex`。折叠组采用最后一个成员的序号；展开组标题使用零，避免不可见子项推进位置。Worker 任务共享父消息序号。

`Sidebar` 的实际尺寸严格为 width × height，包含完整外框和内缩分隔线。SESSION 显示名称、cwd、可选 Git 以及 CTX 进度/用量；STATS 以对齐的两列显示小写 `in/out` 和 `cache/cost`，符合条件的 Codex 配额增加可选行。RECENTS 作为该区域标题；`+ New session` 是历史视口下方固定、占满内部宽度的点击目标，之间空一行。视口最多显示五个单行历史名称，且受高度约束，为已打开会话卡片留出空间；点击行恢复对应会话。`SidebarGeometry` 限制 `HistoryOffset`，名称带缩进、不带序号，并按宽度截断。悬停仅将名称前景改为浅紫色，不添加背景；当前会话本身不高亮。全移动鼠标报告保留正文拖拽能力；悬停由指针坐标和当前布局计算，滚动及刷新后也同样更新。历史溢出时列表显示细滚动条。UI 提供全部已保存会话，并独立路由历史/已打开标签的滚轮事件。两行高的已打开会话卡片前只有一行空白、没有分隔线；不存在折叠或 SESSIONS 标题。`SidebarGeometry(height, context)` 是可选行、容量和点击范围的权威来源。模型/思考控制属于输入页脚，不在侧栏。

本包不创建子进程、不访问网络、不修改设置、不访问凭据，也不执行模型。
