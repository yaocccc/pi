# pi-goui implementation contract

Independent Go/Bubble Tea v2 frontend. Reference pitago's component/module split and RPC transport lifecycle, not its application UI. Existing pi is authoritative and runs as a separate `pi --mode rpc` subprocess per opened session. No copied credentials, injected extensions, or modification of original settings on startup. Each open session retains its process, editor draft, messages, queue, pending extension dialogs and stream when another session is focused.

## Stable package boundaries

* `internal/rpc`: `Config{Bin,Cwd,AgentDir,SessionFile string; NoSession bool; Args []string}`; `Start(Config)(*Client,error)`; `Client.Call(context.Context,map[string]any)(json.RawMessage,error)` returns **response.data**, `Send(context.Context,map[string]any) error` for extension UI responses; `Events() <-chan Event`, Event {Data json.RawMessage; Err error}; `Close() error` idempotent bounded; `PID() int`. Events only unsolicited events, not command responses. Explicit PI_BIN never silently falls back. No model calls at startup.
* `internal/session`: public types in types.go. `State.Apply(json.RawMessage) bool` applies streaming/lifecycle/queue events and returns whether authoritative refresh is advisable; Busy only cleared by agent_settled (not prompt acknowledgement). `LoadState(json.RawMessage) error`, `LoadStats(json.RawMessage) error`, `LoadEntries(json.RawMessage) error` (get_entries returns {entries,leafId}), `LoadMessages(json.RawMessage) error` fallback if needed. Full active-branch message records remain visible across compaction; summaries must not replace originals. `ReadFile(path string)(json.RawMessage,error)` returns get_entries-compatible JSON; `List(root,cwd string)([]Summary,error)` lists native session JSONL under root/sessions, current cwd only (empty cwd means all). History reads are read-only except explicitly requested session rename/delete: closed v3 files are validated and identity-checked before appending native session_info or unlinking the exact selected file. Open-session rename uses RPC; deletion waits for its writer to close. No recursive deletion. MessageCount/MessageIndex count native records on the active branch, not rendered rows.
* `internal/config`: `Load(cwd string)(Config,error)`, `AgentDir() string`; Config {AgentDir string; Keys Bindings; Theme Theme; Settings map[string]any}. `Bindings.Match(action,chord string) bool`, `Keys(action string) []string`, `Actions() []string`. `CanonicalKey(string) string`, `KeyChord(tea.KeyPressMsg) string`. Full pi 1.5 action defaults + keybindings.json string/array overrides, [] disables. Single theme based on themes/pi.json. Theme {Accent,Border,Muted,Text,Background,UserBackground,AssistantBackground,ToolBackground,Success,Error,Warning,Thinking string}; Get(name string) string optional. Settings global and project shallow top-level merge (nested maps recursively merge if native pattern says so). Read only.
* `internal/input`: `type Editor struct { Area textarea.Model; ... }`; `New() Editor`; `(*Editor).Update(action string,msg tea.Msg) tea.Cmd`; `SetValue(string)`; `Value() string`; `Jumping() bool`. Named pi editor actions, newline, ordinary typing/paste, kill/yank/undo. No default Bubbles shortcuts leaking into disabled/remapped actions. App owns history/submit/completion/modal/global actions. Virtual cursor is disabled; UI translates Area.Cursor() using the same frame/popup/viewport geometry as rendering and publishes tea.View.Cursor for terminal IME anchoring.
* `internal/render`: pure view functions using config.Theme and session.Item. `Options{Width,MessageCount int; AssistantTitle string; ExpandTools,ShowThinking bool; Expanded map[string]bool}`; `Transcript(items []session.Item, theme config.Theme, opts Options) Document`. Document carries Text, Blocks and MessageCount; Block carries ID/Role, Start/End, MessageIndex and effective Foldable/Expanded state. Width including outer padding never exceeds opts.Width (minimum 1). Markdown/code highlighting, clearly separate user and assistant bubbles; tools start as compact single-line cards expandable individually or globally. Hidden thinking stays in model. Running tools, error outputs and compaction boundary labels styled. No hard history truncation. Can cache per-width Markdown renderers; do not reuse mutable state unsafely. `Sidebar(state session.State, sessions []SessionRow,theme config.Theme,width,height int) string`; SessionRow {ID,Name,Status string; Active bool}; SESSION holds name/cwd/optional Git/context; STATS uses two compact columns; eligible Codex quota is optional, followed by + New and cards without a SESSIONS heading. Model/thinking controls are in the input footer. No files/themes/plugins tabs. Sidebar may be hidden by main layout on narrow terminals.

## UI owned by main agent
cmd/pi-goui, internal/ui: lifecycle routing, inputs and dialogs, per-session state, scroll and folding hit tests, slash command completion, native action dispatch, full-history refresh on settled/start/resume, session picker/new/switch without cancelling background processes. Preserve user override Ctrl+Y => resume. Config reload from /reload. Extension select/confirm/input/editor and notifications stay scoped to originating session. Popups sit directly above the input frame and preserve the backdrop. Slash matching is fuzzy (Enter executes, Tab completes); file references use bounded asynchronous indexing. Esc has priority over completion while an active/pending prompt can require abort. Resume replaces the current slot with a fresh internal ID or activates an existing target; draft/busy loss requires confirmation. Selector rename/delete is selection-bound and reserves its target against concurrent in-app mutation/resume. No model calls during automated checks. Exit/suspend handled by Bubble Tea, final close cleans all children.
