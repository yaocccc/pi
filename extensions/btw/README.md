# BTW：临时只读问答

参考 [dbachelder/pi-btw](https://github.com/dbachelder/pi-btw) 的弹窗体验，独立实现的精简版本。只注册 `/btw`，不包含工具、持久化线程、模式切换或回写主会话功能。

位于 `~/.pi/agent/extensions/btw/index.ts`，由 Pi 自动发现；新安装后运行 `/reload`，或重启 Pi。

## 使用

- `/btw` 或 **Ctrl+B**：打开弹窗，再输入问题。
- `/btw 这段方案有哪些风险？`：打开并立即询问。
- **Enter**：发送；回答结束后可以继续追问。
- **PageUp / PageDown**：滚动回答。
- **Esc / Ctrl+C**：立即关闭；正在进行的请求同时收到取消信号。

采用打开时的当前有效分支上下文快照（包含压缩摘要与上下文编辑），以及当前模型、推理等级、提供商和认证配置。父会话随后新增的消息不会同步到已打开的弹窗。

## 只读与销毁边界

- 不向模型提供工具，不运行 agent 工具循环；不能读写文件、执行命令或主动检索外部信息。历史工具结果仅作为上下文。
- 不创建子会话文件，不向主会话添加消息、用量条目或自定义条目。
- 问答仅保存在当前弹窗实例的内存中；关闭会清空实例数据、取消请求，并忽略迟到的响应。再次打开不继承上次问答。
- 错误会显示在弹窗内；失败请求不会加入后续追问的模型历史。
- 模型请求仍会发送上下文给当前提供商并产生正常 API 用量；“销毁”不意味着删除提供商服务端日志或已产生的计费。
- 需要交互式终端 UI；不支持 print/RPC 模式。

## 验证

```sh
node extensions/btw/tests/run.mjs
```

测试使用全局安装的 Pi 及其 esbuild，可用 `PI_CODING_AGENT_DIR` 指定其他安装路径；不安装依赖、不调用真实模型。覆盖上下文分支选择、数据隔离、连续追问、错误恢复、窄屏与宽字符、关闭取消、迟到事件与命令前置检查。

实际终端验收建议：运行 `/reload` 后测试空参数与带问题打开、中文输入、长回答翻页、缩放窗口，以及生成中按 Esc 后重新打开。自动化测试不替代真实终端与提供商的端到端验证。
