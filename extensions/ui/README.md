# UI 展示与工具折叠

本扩展只改变展示，不改写用户消息、助手消息、thinking 或工具原始记录。

## 消息框与输入框

- 用户消息使用右对齐的圆角气泡框，标签为“你”；短消息随内容收窄，长消息在终端约 80% 的宽度内换行。不铺背景，保留原生 Markdown、语义标记及鼠标交互。
- 同一轮助手的说明、工具状态、预览和最终结论共用一个左对齐圆角框。短内容随实际内容与标题收窄，长内容按可用宽度换行；图片保留原生布局。
- 助手框顶边仅显示“供应商 · 模型名称”，取自该轮最后一个带模型信息的实际助手消息，不使用当前选中的模型冒充历史模型。缺少模型信息的旧消息回退为“助手”。
- 完成后不再折叠此前的说明与步骤，顶边也不再提供整轮折叠按钮或显示统计。工具组和单次工具输出仍可独立折叠。
- 助手消息及整个框底部不保留额外空白行；正文段落间距、原生语义标记和图片占位行保留。宽度不足 8 列时使用无框布局。
- 底部输入框保持全宽，使用细线圆角边框，不铺背景。保留原生输入、粘贴、快捷键、滚动提示和光标；补全菜单与 working message 在框外。
- 三种框使用不同色系：用户框为青绿色、助手框为蓝色、输入框为淡紫色。各自保留协调的八段配色，不使用 dim 或弱化色。
- 配色集中在 `utils.ts` 的 `FRAME_COLORS.user`、`.assistant`、`.input`，深浅主题切换不改变边框色；标签保持普通文字样式。

## 长消息重绘

用户框、助手框和工具框复用未变化的格式化行。已完成、纯文本且能确认原生 renderer 身份的工具可直接复用最近快照；运行中、图片和未知自绘 renderer 仍实时渲染，保留动态可见性与鼠标布局。原生 bash 的 renderer 由工厂逐次生成，无法以函数身份确认，因此保守走实时路径。宽度、内容、留白、主题或原生失效通知会触发重算；流式助手继续复用原生 Markdown 分块缓存。

稳定的纯文本助手与已完成、关闭的工具组还可复用整轮输出及原生鼠标布局，跳过子树渲染和逐行比较。助手以原生 children 数组识别同对象更新；工具以 `updateDisplay` 更新令牌及状态识别变化。宽度、主题、组件身份、留白或折叠变化会失效。展开组、流式、Worker、图片、自定义 Markdown transformer 和未知 self renderer 保留实时路径；关闭组中本来就不绘制的空助手载体不阻止复用。即使文字相同，替换组件后也会刷新鼠标布局及快照身份。历史投影仍实时执行，不缓存或裁剪会话记录。

助手框与工具大快照共享 **128 MiB 估算预算**，弱引用索引不保活旧会话；预算耗尽时正常重算，不丢历史、不改变复制或搜索内容。同一遍历史渲染保护已命中缓存，避免逐条相互淘汰。折叠工具会释放展开快照及原生子组件的渲染缓存，切换会话或分支会清空大快照。截断预览不再额外保存完整输出数组。此预算不是进程总内存上限：原生组件、布局全行和小型标题缓存仍会占用内存；超出预算的超长展开历史仍可能变慢。

测宽与补白对普通字符和边框使用与原生逐字节一致的快速路径，复杂 Unicode、ANSI 跨段字素及图片协议保守回退。完整工具输出只在请求展开时生成，不因输入或滚动预先展开；本扩展不使用视口占位或截断历史。

### 固定长会话回放：有界快照阶段

基准固定真实分支的前 1,466 条消息、688 个工具，比较回退点 `4d1a9dc` 与 `76ac78f`；固定样本仅用于测量，生产历史不裁剪。下表为同一无输出终端回放，耗时不包含展开状态切换的约 0.2–0.3 秒；heap 为强制 GC 后的 V8 堆，不是纯缓存占用。

| 指标 | 回退点 | `76ac78f` |
| --- | ---: | ---: |
| 首次全展开渲染 | 14.06 秒 | 4.78 秒 |
| 再次全展开渲染 | 11.77 秒 | 4.47 秒 |
| 展开后输入 / 光标 / 滚轮中位数 | 63 / 59 / 43 ms | 37 / 34 / 34 ms |
| 首次展开 heap | 209.7 MiB | 192.9 MiB |
| 再折叠 heap | 151.4 MiB | 91.0 MiB |
| 展开状态缩放至 80 / 120 列 | 13.85 / 14.35 秒 | 4.68 / 4.76 秒 |

折叠热态仍约 1–2 ms；首次折叠渲染在此次测量中为 103 → 148 ms，并非所有阶段都加速。全展开估算缓存为 116.7 MiB；开启与禁用缓存的完整 94,264 行摘要校验一致。原生全展开首帧约 1.67 秒、热态约 4–5 ms，仍明显更快。

回放不含真实终端 I/O、完整编辑器、footer/workbench，自绘扩展使用原生回退，不能替代完整重启后的真实终端验收。连续缩放后的 RSS 仍约 537 MiB；预算不会限制原生布局或要求 V8 立即归还内存。

### 折叠整轮复用回放

仅将 `rounds.ts` / `folding.ts` 回退至 `76ac78f` 作基线，其余依赖与扩展保持相同。每组交错运行 3 对独立进程，每个事件采样 100 次；下表为各次中位数的中位数。5 倍样本重复固定分支，仅用于压力测量，不代表另一个真实会话。

| 折叠状态 | 原实现 | 整轮复用 |
| --- | ---: | ---: |
| 1,466 消息：输入 / 光标 / 滚轮 | 1.27 / 1.14 / 1.22 ms | 0.97 / 0.85 / 0.87 ms |
| 1,466 消息：滚轮 p95 | 1.96 ms | 1.40 ms |
| 7,330 消息：输入 / 光标 / 滚轮 | 6.09 / 4.85 / 5.39 ms | 4.09 / 3.97 / 4.09 ms |
| 7,330 消息：滚轮 p95 | 7.57 ms | 5.40 ms |

固定样本的 41/50 轮可复用；滚轮中位数分别降低约 29% 和 24%。折叠快照估算仅从 0.335 增至 0.338 MiB，仍使用原 128 MiB 预算。完整 816 行、5 倍样本 4,080 行，以及全展开 94,444 行均通过开启/禁用缓存逐行或摘要一致性检查。鼠标同文本 A→B→A 替换、同对象更新、动态自绘、主题、宽度及预算耗尽有专项回归。

这不是冷态或全展开优化：初次折叠约 137→152 ms，5 倍样本约 507→498 ms；全展开另做 3 对进程、每事件 30 次采样，输入 / 光标 / 滚轮约 33.1 / 32.6 / 32.7→35.0 / 34.6 / 32.9 ms。展开相对构建后的 GC 堆增量仍约 115 MiB，连续缩放 RSS 约 541 MiB。未用更大缓存换取收益；完整历史投影、布局及终端输出仍有成本。以上仍是无输出终端回放，**需完整重启后在真实终端验收，不能用 `/reload` 替代**。

## 分轮与恢复

用户消息通常标记新一轮开始。已保存的 `ui-round-summary` 隐藏元数据也可标记一轮结束，用于区分没有额外用户卡片的扩展 follow-up。

- 沿用 `agent_end` 冻结、`agent_settled` 保存的元数据流程，避免把尚未真正结束、错误或取消的阶段当成完整轮次。
- 元数据中的旧统计保留兼容，但不再展示或控制折叠；原始记录不变，元数据不加入模型上下文。
- 重载、恢复和切换分支时按当前分支重新分轮。没有元数据的历史也使用助手框与实际模型标题，不补造统计。
- 上下文压缩只影响发给模型的内容，不缩短界面历史。恢复及成功压缩后从当前分支的完整原始记录重绘，保留旧消息、工具结果和压缩提示；不混入其他分支，也不修改上下文投影或记录。
- 正常保存后清除编辑器中的已完成 working message，执行中的 working message 不受影响。

## 执行中：说明在工具组外、助手框内

助手说明保持原位置，说明下面不额外插入空行；紧随其后的工具摘要直接接在说明后。新的说明切分工具组，空的工具调用载体和隐藏 thinking 不切分相邻工具调用。

工具组默认显示调用数量、分类、运行或失败状态，以及紧跟其后的 token 估算：

```text
 › 1 call · bash×1 ≈202 tok
```

工具区域采用无树线列表：摘要缩进一格，调用行（含 Worker task 行）再缩进两格。调用箭头与普通工具、原生 edit、Worker 的展开框及截断提示统一左对齐，不绘制额外树枝或连接线。窄屏自动缩减，其他自绘内容及图片保持原生布局。分类使用 dim，标题、箭头及工具名为普通文字；running/failed 紧跟分类。汇总 token 不再靠右对齐，调用行保留 token 展示。

- 折叠标记统一为 `›`（收起）和 `⌄`（展开），用于工具组、调用行及 Worker 预览。
- 点击工具组摘要展开调用行。
- 展开的普通工具和 Worker 使用蓝色八段圆角细线框；提问面板使用淡紫色细线框。不填充外壳背景，只调整工具实例，不修改全局 Box/Text 渲染。
- 工具框标题显示工具名，完成后追加 token 估算，例如 `╭─ codemode ≈9.8k tok ─…╮`。只从正文中移除单独一行的重复工具名，原生参数、状态、代码与结果不变。
- 边框单独占一列，框内水平留白遵循当前 `outputPad` 设置（支持动态更新，窄屏自动缩减）；token 不占用正文或右侧留白。折叠摘要保持紧凑，隐藏控制行不生成空框。
- 单个工具点击循环为：收起 → 原生缩略预览 → 完整输出 → 收起；若缩略已经显示全部内容，则第二次点击直接收起。点击调用行切换，工具组摘要仍只控制整个组；边框仅拦截左键点击，不触发内容控件。
- 缩略预览最多 12 个终端行，保留完整底边，超出后提示再次点击或 `Ctrl+O`；图片保持原生布局。截断底边与提示不转发隐藏控件的点击。运行中、失败或自绘工具都不会自动展开完整输出。
- `Ctrl+O` 查看或收起完整工具输出，不隐藏助手说明或最终结论。
- 原生缩略控件、可点击区域和鼠标捕获保持有效；边框及框外空白不转发为工具内容点击。

## Worker 实时预览

活跃 Worker 批次按 task 显示排队、运行、完成、失败和阻塞状态。行顺序为：状态、模式、new/fork 图标、实际档位（无则请求档位）、Turn、输入/输出 token、耗时、任务名称。

- 第一个结果到达前，从调用参数显示排队任务。
- 批次完成后自动收回默认预览；用户主动打开的预览保留。
- 复用 Worker 现有快照与刷新机制，不增加计时器、不跨会话查询。历史耗时按快照冻结。

所有 thinking 均不展示，包括实时、完成、历史及完整展开的 Worker 卡片；原始内容保留。没有可见内容时不生成空助手框，没有工具时不生成空工具组；独立错误提示正常显示。

一般更新可执行 `/reload`。移除旧单行压缩或半高背景补丁后，需要重启 Pi，避免当前进程仍调用旧的工具或 Box/Text 渲染包装器；仅 `/reload` 无法卸载这些旧闭包。很旧的 thinking 预览或间距补丁也需重启清除。本次三段切换与渲染缓存同样包含原型闭包更新，需要重启 Pi 后生效。
