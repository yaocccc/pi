# 扩展精简审查

本轮覆盖 `extensions/` 的全部扩展目录及根入口文件，排除依赖和锁文件。以开始时的工作区为基线，保留已有未提交修改；没有恢复已删除扩展、升级依赖或更改运行配置。

## 覆盖与取舍

| 扩展 | 处理 |
| --- | --- |
| `ask-question` | 合并单选固定项/自定义项结果构造；保留文案、字段、问卷与取消行为。已有提示压缩保持不变。 |
| `autoname` | 仅保留自动命名；按用户要求移除历史会话批量命名命令及专用逻辑。独立命名请求不计作主会话常驻上下文。 |
| `codex-fast` | 保留：供应商请求路由行为敏感，没有值得改变的重复主会话提示。 |
| `commit` | 保留：按需工作流说明承担操作约束，不为缩短文本删除提交安全规则。 |
| `filter-output` | 保留：输出过滤规则与预览限额直接影响可见结果。 |
| `memory` | 统一 CommitMemory 到 IndexEntry 的字段投影；不改持久化、压缩决策、清理顺序或记忆提示约束。 |
| `sol-pi` | 仅保留 Observation Pack 与 OCC，缩短占位文字并隐藏额外界面；移除 Action Fusion，由 codemode 串联原生文件操作和后续命令。OCC 算法、版本门禁及上下文恢复协议不动。 |
| `telegram` | 保留：通知、认证与异步生命周期不宜为减少行数重排。 |
| `thinking-translation` | 新块初始化复用 `ensureBlock`；请求时机、版本失效、完成状态与原思考内容不变。 |
| `ui` | 统一计时器清理，移除未显示的首 token 延迟状态；保留公开可选参数兼容性、布局与 token 统计。 |
| `worker` | 模型侧结果 JSON 去掉缩进，解析结果及 UI details 不变；已有工具描述与子提示精简保持不变。 |
| `herdr-agent-state.ts` | 保留生成的状态集成代码，不修改外部协议。 |

代码减少不等于模型上下文减少。UI、通知和命令选择数据不计入常驻上下文收益，也不通过删除安全规则换取体积下降。

## 可重复测量

以下均为 **UTF-8 字节**，不是实测 token 数；结果类指标随内容变化。

| 文本 | 本轮前 | 本轮后 |
| --- | ---: | ---: |
| OP 典型 400 行结果的占位符 | 1425 | 1360 |
| Worker 典型双任务结果 | 4288 | 2569 |

OP 保留 id、工具名、原始字节/行数/token 估计、前后完整行、首次完整发送次数及 `offset` / `next_offset` 恢复说明。Worker 原始 JSON 不再缩进，但现有卡片仍从 `details` 渲染。

## 再次复核

- 修复既有的 Worker 诊断截断：固定 `execution` 字段不再受通用对象键数上限影响，保留 `warnings`、`termination` 和 `termination_source`；字段值仍受原嵌套深度、长度及数量限制。
- Worker 大小预算与最终输出统一使用紧凑 JSON，避免仅因缩进空白而过早删减结果。新增回归测试先复现两项问题，再验证修复。
- 同步中英文 README 中过期的 Fast 模型前缀说明；不改变请求路由或本地配置。

这些修复优先保留必要信息，不以丢失诊断换取更小输出。极端超限时的既有状态摘要降级仍保留，不保证完整结果永不截断。

## 验证

```sh
node --experimental-transform-types --test extensions/*/*.test.ts \
  extensions/sol-pi/tests/context-footprint.test.mjs \
  extensions/sol-pi/tests/observation-pack.test.mjs
git diff --check
```

移除批量命名命令、设计指令扩展和 Action Fusion 后，回归结果：225 项通过，包括 JSON 等价性、诊断保留与字节预算边界、选择结果、字段投影、计时器生命周期、翻译块状态、UTF-8 占位边界、实际归档/分页还原和 OP/OCC 完全隐藏的卡片渲染。所有非 SoL-Pi 扩展加 OP 与 OCC 工具层入口（共 85 个）通过严格 TypeScript 检查。另以当前全局 SDK 的真实工具组件补验隐藏渲染，120 次断言通过。

### 既有验证限制

SoL-Pi 的 `tests/run-global.mjs` 明确要求 Pi **0.87.1**，本机全局版本为 **1.0.2**，因此其完整集成测试不能按原入口运行。工作区依赖下，全目录类型检查原有的 OCC 兼容错误前后完全一致；本轮未修复或掩盖它们。新增独立测试不加载 OCC 的固定版本实现，不代表完整 OCC 集成验证。真实终端交互与跨平台进程清理仍需环境 smoke test。
